# zerodayFind APT 武器化流程（优化版）

## 设计原则

1. **最小化人类介入** - 只在关键战略决策点介入
2. **AI 主导执行** - 80% 工作由 AI 自动化完成
3. **人类只做战略决策** - OPSEC、风险控制、最终审核
4. **异步审核** - 人类不需要实时等待，可以批量审核

## 人类介入点设计（优化后）

### 原则：最小化 + 战略级

```
┌────────┬────────────────────────┬───────────────────────────────┐
│ 阶段   │ 人类介入点             │ 介入时机 & 性质              │
├────────┼────────────────────────┼───────────────────────────────┤
│ 1.挖掘 │ ❌ 无                  │  AI 全自动，人类事后查看报告 │
├────────┼────────────────────────┼───────────────────────────────┤
│ 2.部署 │ ❌ 无                  │  AI 全自动，部署失败自动重试  │
├────────┼────────────────────────┼───────────────────────────────┤
│ 3.验证 │ ⚠️  异常触发           │  失败>3次 或 连续失败        │
│        │                        │  → 告警通知，人类决定是否继续 │
├────────┼────────────────────────┼───────────────────────────────┤
│ 4.链条 │ 🎯 战略决策 (异步)     │  AI 生成 3 套方案            │
│        │                        │  → 人类选择合适方案            │
│        │                        │  → 可批量审核（不必实时）      │
├────────┼────────────────────────┼───────────────────────────────┤
│ 5.映射 │ ❌ 无                  │  AI 全自动，风险高时自动调整  │
├────────┼────────────────────────┼───────────────────────────────┤
│ 6.武器 │ 🔒 最终审核 (同步)     │  最后一次人类检查机会         │
│        │                        │  → OPSEC 合规                 │

│        │                        │  → 部署方案确认                │

```

**总结**:
- ✅ **4 个阶段完全自动化**（阶段 1/2/3/5）
- ⚠️ **1 个阶段异常触发**（阶段 3 - 验证失败告警）
- 🎯 **1 个阶段异步决策**（阶段 4 - 人类选择方案）
- 🔒 **1 个阶段同步审核**（阶段 6 - 最终 OPSEC 检查）

## 异步审核机制

### 设计思路

人类专家不需要实时等待 AI 完成每个阶段，而是：

1. **AI 批量处理** - 同时处理多个目标/漏洞
2. ** checkpoint 队列** - 需要人类决策时加入队列
3. **人类定期审核** - 每天 1-2 次批量处理队列
4. **紧急告警** - 高风险事件实时通知

### 实现方案

│  └─────┬─────┘    └─────┬─────┘    └─────┬─────┘    │
│        │                │                │          │

│  │       人类审核队列 (Checkpoint Queue)      │      │

## 异常处理机制

### 阶段 3 验证循环（详细逻辑）

```
┌───────────────────────────────────────────────────────┐
│           阶段 3: 漏洞验证 (Verification Loop)         │
├───────────────────────────────────────────────────────┤
│                                                        │
│  for i in range(10):  # 最多 10 次                   │
│    │                                                  │
│    ├─ AI: 生成 PoC                                   │
│    ├─ AI: 在隔离环境执行                              │
│    ├─ AI: 解析结果                                    │
│    │    ├─ [成功] → 记录利用路径, 跳出循环             │
│    │    ├─ [失败] → 分析失败原因                      │
│    │    └─ [超时] → 调整阈值, 重试                   │
│    │                                                  │
│    ├─ AI: 自动修复 PoC                                │
│    ├─ 更新 Blackboard 置信度                          │
│    │                                                  │
│    ├─ [失败次数 > 3] ?                               │
│    │    ├─ [是] → 触发告警, 通知人类                  │
│    │    │             "验证失败超过 3 次, 是否继续?"  │
│    │    └─ [否] → 继续循环                           │
│    │                                                  │
│    └─ [人类决策: 放弃] ?                              │
│         ├─ [是] → 返回阶段 1, 重新挖掘               │
│         └─ [否] → 继续循环                           │
│                                                        │
│  [循环结束]                                           │
│    └─ [仍未验证通过] → 标记为"验证失败"               │
│                       → 归档 + 通知人类                │
└───────────────────────────────────────────────────────┘
```

## 实施建议

### 优先级排序

```
┌────────┬────────────────────────┬────────────────────────────┐
│ 优先级 │ 模块                   │ 原因                        │
├────────┼────────────────────────┼────────────────────────────┤
│ 1️⃣ 高  │ engine/verifier.py     │ 核心模块, 决定能否武器化    │
│        │ (阶段 3 验证器)        │                            │
├────────┼────────────────────────┼────────────────────────────┤
│ 2️⃣ 中  │ engine/chain_builder.py│ 需要人类决策, 但可先人工    │
│        │ (阶段 4 链条设计器)     │                            │
├────────┼────────────────────────┼────────────────────────────┤
│ 3️⃣ 低  │ server/checkpoint_api  │ 异步审核机制, 可后期优化    │
│        │ (checkpoint 队列)       │                            │
└────────┴────────────────────────┴────────────────────────────┘
```

### 第一阶段实施计划

**目标**: 实现最小化可行流程（不需要人类介入）

1. **实现 `engine/verifier.py`** (阶段 3)
   - PoC 自动生成
   - 自动修复 & 重试
   - 验证结果解析

2. **实现 `engine/chain_builder.py`** (阶段 4)
   - 自动生成 3 套方案
   - 输出到文件（人类手动选择）

3. **实现 `engine/weaponizer.py`** (阶段 6)
   - 自动生成武器平台
   - 输出到隔离目录

4. **后期添加人类审核队列**
   - 实现 `server/checkpoint_api.py`
   - 实现异步审核界面

## 关键改进点

相比第一版设计，优化版：

1. ✅ **减少人类介入** - 从 6 个降到 2-3 个
2. ✅ **异步审核** - 人类不需要实时等待
3. ✅ **异常触发** - 只在出现问题时通知人类
4. ✅ **批量处理** - AI 可以同时处理多个目标
5. ✅ **战略决策** - 人类只做高层决策，不介入执行细节
