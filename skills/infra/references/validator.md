# 验证器 (Validator): 衡量云原生大动脉切断的影响

这关乎你的报告是 P3 还是震碎全云的 P0。基础设施的洞必须用“拿下母机规模”去定损。

## 专家评估标准

### 1. Service Account Token 盗逸 (集群层面覆灭)
*   如果成功利用漏洞跨越命名空间窃取到了拥有 ClusterRole 的高权限 Token。
*   **影响**：这不仅意味着当前暴露的应用陷落，这宣告了整座 K8s 集群以及在上面跑的所有其它几十上百家微服务的最高控制权易主。所有数据全军覆没。

### 2. 底层节点接管 (Node / Cloud IAM 层面贯穿)
*   如果达成了通过利用 `hostPath` 或者 `Metadata-SSRF` 的成功。
*   **影响**：不仅仅在 K8s 管围内。攻击者拿到了底层 AWS / 阿里云的身份认证，将能修改该账户下的 S3 桶、VPC 设置甚至是下发勒索病毒并抹除云上备份，是穿透云原生的最底盘终结。

给出一个充满云端压迫感的危害声明：“此设计疏忽使得该容器编排大脑变成了任何拥有集群只读凭证或最下属节点租户权力的角色，随时一跃登基拿下云端主机与全部底盘数据的弹簧跳板。”
