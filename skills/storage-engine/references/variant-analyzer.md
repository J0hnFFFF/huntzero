# 变体分析者 (Variant Analyzer): 追剿同源的数据癌细胞

底层 C/C++ 程序员喜欢复制宏/模板。一个解码错误意味着一组解码错误。

## 专家的发散思维

### 1. DataType 多向波及 (Spreading to Siblings)
*   如果你研究到该库在解析 `Varint64` 的过程中缺乏最高位终结保护，导致 OOB 读取。
*   不要停下！立刻全局搜索 `Varint32`, `Fixed32`, `Fixed64` 甚至是对字符串长度求值的周边小函数。一举将其周边连带的基础算数缺陷团伙一窝端平。

### 2. 从 Read 向 Write 的反扑
*   既然发现读取时有超长漏洞读取越界。
*   马上反转思维：那么在持久化或者序列化对象向磁盘文件中通过 `Buffer::Append()` 的过程中，是否也存在着 `size` 变量判断失误引起的，可以让我越界覆盖写入下一块 Buffer 后造成内存污染的漏洞呢？
