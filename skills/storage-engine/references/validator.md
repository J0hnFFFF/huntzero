# 验证器 (Validator): 衡量底层支柱崩解的影响辐射

在存储级层面出的漏洞无一不是 P0 灾难级。必须精准判决它是使得该存储服务器永久拒服，还是使得寄存于此的业务权限全部丢失！

## 专家评估标准

### 1. 内存污染主导权易主 (Heap RCE - 全盘接管)
*   如通过精心准备的溢出或者 OOB 修改，篡改了一个 C++ 对象的 Virtual Table（虚函数表）或者底层指针。
*   **影响**：这不仅宣告了当前数据库实例被攻陷，这等于拿到了整台安装了 Redis / TerarkDB 宿主服务器的任意系统命令执行权力。该攻击往往是静默的持久化毒瘤。

### 2. 崩溃或死循环拒服 (Core Abort / Deadlock DoS)
*   通过发去几个特殊构造畸形的 Request 或查询含有被故意污染的 Block 的时候。
*   **影响**：立刻导致整个高频存储端 Coredump 秒杀退出，使得以毫无保护的高并发重试的上层业务（如所有的 Web 网关和微服务）立即陷入连环爆炸停摆状态，致全系统宕机。

## 你的使命
给出一个压迫感满载的威胁评级。宣告由于引擎底层的数字或边界管理疏漏，让原本稳固如玄武岩的数据层基地变成了被任人引爆控制和提取最高系统权力的火药桶。
