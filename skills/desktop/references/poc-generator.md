# PoC 生成器 (PoC Generator): 锻制绝对证明体系

让防御者无可辩驳地承认：前端缺陷确确实实通过了他们自以为无懈可击的封装，在宿主机实体中产生了杀伤。

## 专家级 PoC 的要求

1.  **分步剥茧的载体**：
    编写一段包含前端 HTML 及用于投毒劫持的 Javascript（PoC.html 等）：
    *   **注入层**：提供一段含有恶意构造 `fetch` 或者利用已有 `window.ipc` 发文的前台语句。
    *   **逃逸层**：指点迷津式地说明，这段语句如何欺利用了被曝光的那段缺乏沙盒拦截控制权的脆弱代码 `ipcMain.on` 的盲目服从。
    *   **落地证实层**：要求弹出一个原本不允许弹出系统核心级应用程序（譬如 MacOS 的计算器 `open -a Calculator`，或是 Windows 的 `calc.exe`）。通过它的弹出来盖棺定论本应禁锢在浏览器沙箱里的 Web 页面篡夺了操作系统控制权。

2.  **CLAIM CHAIN 必须包含双进程落点**：
    必须在这指明这跨越维度的罪过是如何成立的。如 `[file: render.js:xx -> file: preload.js:yy -> file: main.js:zz]` 的精确传送路线。

## 你的任务
产出具有高视觉冲击力的（例如从一个普通文字页内突然弹开底层 CMD）系统接管代码论证样本。
