# 验证器 (Validator): 衡量跨架构跳跃的穿透力

一个桌面端漏洞的破坏力不仅仅是“能够任意读文件”，它的威胁性由前提条件的隐蔽度来界定。

## 专家评估标准

### 1. 0-Click (零交互无触触发) 威胁统治
*   若该漏洞通过自定义协议 `myapp://` 或者是在不安全的网页预览加载中自动完成，无需被害者主动去“点击某文件”：
*   **影响**：Critical 级。只需往论坛或是任意存在流量的地方发布暗藏协议或者链接的网图/框架，任何安装该应用的系统就会在后台悄然拉取后门，全自动成为肉鸡（Botnet）。

### 2. XSS 辅以放行特权 (RCE directly)
*   若因缺乏 Node 集成剥离和严格的 ContextIsolation：
*   **影响**：这不再是一个用户体系的数据泄露，而是受害者这台物理设备的沦陷。等价于向网络对面让交出本台物理机的反弹 CMD (Reverse Shell)。
