# 变体分析者 (Variant Analyzer): 发掘平行的特权隧道

专家深信：一个粗心的漏洞开发者绝不会只写错一个 API 护栏。

## 专家的发散思维

### 1. 平级 IPC Handler 变种
*   如果一个名为 `export-pdf` 的 IPC 通道里在写入文件时存在路径遍历的后门引发了任意写漏洞。
*   你的眼光必须立刻平移扫描所有 `save-*`, `download-*,` `cache-*`，它们很有可能使用了同一套完全没有过滤 `../` 的封装好的公用方法。

### 2. 外部调用的蔓延
*   既然你发现在打开外部网页功能 `shell.openExternal()` 处能使用 `file://` 来突破。那么审查应用调起的所有其他机制（无论是通知气泡 `Notification.onclick`，亦或是协议 `app.on("open-url")`）中所隐含的其他入口逻辑是否也共享这一隐患。
