# 代码理解

系统性理解代码库整体架构、模块关系和功能流程。

## 任务

不带任何预设，全面阅读代码库。

## 输出要求

### 1. 整体架构
- 描述模块依赖关系
- 识别核心组件
- 标记入口点

### 2. 关键流程
- 数据输入流程
- 处理逻辑流程
- 输出操作流程

### 3. 关注点清单
- 潜在风险区域
- 可控输入点
- 敏感操作位置

## 分析原则

- 不带预设，客观阅读
- 关注数据流向
- 标记可控输入点
- 记录潜在风险区域

## 输出格式

```
## 架构概览
[描述]

## 关键流程
1. [流程名称]: [描述]

## 关注点
| 位置 | 类型 | 说明 |
|------|------|------|

## 可控输入点
- [输入点]: [描述]
```
