# 目标定义

定义反制目标，明确优先级。

## 核心诉求

反制攻击者：
- 控制目标
- 获取信息

## 反制优先级

```
1. 远程控制 - 最高价值
2. 信息获取 - 次高价值
3. 其他手段 - 备选
```

## 目标函数/操作

需要寻找的目标：
- 可执行操作的位置
- 可读取信息的位置
- 可外发数据的位置

## 输出格式

```
## 反制目标
1. [主目标]: [描述]
2. [次目标]: [描述]

## 目标清单
| 优先级 | 操作 | 位置 | 可达性 |
|--------|------|------|--------|

## 攻击面分析
[描述可利用的攻击面]
```
