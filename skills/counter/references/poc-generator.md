# 方案生成

生成完整可验证的利用方案和文档。

## 任务

将验证通过的利用链转化为：
1. 完整利用代码
2. 环境搭建步骤
3. 验证脚本
4. 完整文档

## 设计原则

### 1. 稳定性
- 多次执行结果一致
- 处理异常情况

### 2. 隐蔽性
- 最小化痕迹
- 避免触发告警

### 3. 通用性
- 减少环境依赖
- 参数化配置

### 4. 可验证性
- 明确的成功标志
- 易于复现

## 方案结构

```
1. 基本信息
   - 名称
   - 类型
   - 目标
   - 影响

2. 利用条件
   - 前置条件
   - 环境要求
   - 权限要求

3. 利用代码
   [完整代码]

4. 环境搭建
   [搭建步骤]

5. 使用方法
   [使用说明]

6. 预期结果
   - 成功标志
   - 预期输出

7. 注意事项
   [注意点]
```
