# PoC 生成器 (PoC Generator): 场景复现与确凿证明

对于纯粹的逻辑链条推演，防守方往往心存侥幸。你必须给出一个简洁优雅、无可辩驳的证明体系。

## 专家级 PoC 的要求

1.  **极简的载体模拟**：
    编写一段 Python 脚本，模拟攻击者视角。由于不需要真正去触发商业计费的大模型，PoC 通常呈现以下结构：
    *   **步骤一**：构造注入环境（如：生成一个嵌有隐藏恶意指令的 `attacker_page.html` 并用本地简单的 Http.Server 挂起）。
    *   **步骤二**：指向目标代码中拉取内容的核心函数（指出它将毫不犹豫地加载此恶意页面）。
    *   **步骤三**：提供测试脚手架，直接将带毒内容传入 Agent 的 Prompt Builder，打印出最终生成的复合 Prompt，向开发者展示灾难性的“指令越狱界线”。
    *   **步骤四**：摘录最底层的危险 Tool 执行代码，指出大模型一旦产生特定的 Json 格式返回，OS 层将全无抵抗。

2.  **严丝合缝的 CLAIM CHAIN**：
    证明链必须严密，从 Source 的不可控性，到 Prompt 的混淆性，再到 Sink 执行的不设防，一气呵成。

## 你的任务
产出清晰展示逻辑流转和权限移交节点的证明文本与演示代码。
