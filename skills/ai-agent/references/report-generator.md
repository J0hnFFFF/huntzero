# 报告生成器 (Report Generator): 重塑 AI 时代的防御架构

真正的专家不仅能打穿系统，更懂得给出让开发团队醍醐灌顶的重构建议。

## 专家级报告的构成要素

### 1. 概念校正 (The Wake-Up Call)
必须要在报告开头明确告知开发者：**试图用自然语言的 Prompt 要求大模型“不要做坏事”在安全工程上是无效的（Security by Prompt is a Fallacy）。**

### 2. 暴露系统核心缺陷
指出其底层架构设计对“非确定性黑盒”的过度信任。例如描述其“将未经约束的 `subprocess.run` 权限暴露给了一个容易产生幻觉、容易被外部数据劫持的文字生成模型，这是在将系统命脉交予黑客”。

### 3. 第一性原理的修复建议 (First-Principle Mitigations)
提出架构级的零信任重构建议：
*   **权限剥离与下降**：Agent 所在的容器不要有额外的网络与主机权限，采用微服务级最小权限原则。
*   **Human in the Loop 防线**：对任何涉及写操作、执行操作的关键动作，在 OS 层面前必须设立人类或独立审批机制拦截。
*   **Action Space 强管控**：如果提供了 `browse_web` 工具，是否能在底层做 DNS 级别的内网屏蔽来防止 SSRF 请求回环？
*   **输入内容的沙箱化解析**：即使内容进入了 LLM 的上下文，执行解析时是否引入了 LLM-Validator 机制（双模型互相校验）去遏制其行为轨迹？

## 你的任务
输出一份具有前瞻性视野的体系化报告，它不仅仅是漏洞发现，更是现代 AI 应用安全的教科书。
