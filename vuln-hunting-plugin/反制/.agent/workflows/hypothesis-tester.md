# 假设验证

快速本地验证假设，过滤假阳性。

## 验证目标

对潜在问题点进行快速验证：
- 确认是否真实可达
- 过滤理论存在但实际无法利用的问题
- 提升效率，减少假阳性

## 验证方法

### 允许的操作
- 逻辑测试
- 模式匹配
- 静态分析
- 单元模拟

### 禁止的操作
- 实际攻击
- 外部网络访问
- 危险操作执行

## 验证流程

```
输入: 潜在问题点 + 初步思路
         ↓
  1. 分析触发条件
         ↓
  2. 构造最小验证用例
         ↓
  3. 本地安全验证
         ↓
  4. 分析结果
         ↓
输出: 验证结论 + 证据 + 建议
```

## 验证维度

### 1. 可达性验证
- 函数是否被调用？
- 条件分支是否可达？
- 输入是否能传递到问题点？

### 2. 可控性验证
- 输入格式限制
- 长度限制
- 过滤机制

### 3. 影响验证
- 触发后能达成什么效果？
- 效果是否符合预期？

## 验证结果

| 结果 | 含义 | 后续行动 |
|------|------|----------|
| 是 | 验证通过 | 进入利用链构建 |
| 部分 | 部分满足 | 深入分析限制条件 |
| 否 | 假阳性 | 记录原因，继续挖掘 |

## 输出格式

```

- 问题点: [位置]

### 验证过程

- 结果: [是/部分/否]

[后续行动建议]
```
