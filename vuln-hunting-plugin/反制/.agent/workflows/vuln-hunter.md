# 漏洞挖掘

深度挖掘，优先默认配置下可用于反制的问题。

## 分析角度

### 1. 输入处理
- 数据接收逻辑
- 参数处理流程

### 2. 数据解析
- 协议解析逻辑
- 格式处理流程

### 3. 文件操作
- 路径处理逻辑
- 读写操作流程

### 4. 配置与依赖
- 默认配置
- 第三方组件

## 深度分析方法

### 深度
从专家和开发者双重视角分析，确保发现的问题：
- 真实可用
- 端到端可验证

### 通用性
优先默认配置下可利用的问题：
- 不依赖特殊配置
- 不需要额外权限

### 诉求驱动
以反制诉求为核心驱动分析：
- 从目标反推路径
- 聚焦高价值问题

### 逻辑层面
从逻辑和实现深挖隐秘问题：
- 边界条件
- 异常处理

### 视角切换
换位思考开发者可能忽略的盲区

## 输出格式

```
## 发现 #N

### 问题点
- 位置: [路径:行号]

### 分析
[根因分析]

### 利用思路
[方法描述]

### 通用性
- 默认配置: [是/否]
- 环境依赖: [描述]

### 等级
[高/中/低] - [理由]
```

## 挖掘策略

```
没找到 → 换角度 → 换逻辑层面 → 换视角 → 深挖
    ↑                                    |
    └────────────────────────────────────┘
```

持续迭代直到发现可用问题或穷尽所有角度。
