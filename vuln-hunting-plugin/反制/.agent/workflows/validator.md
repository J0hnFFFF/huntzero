# 评估验证

评估问题的通用性、稳定性和实战价值。

## 评估维度

### 1. 通用性

核心问题：默认配置下是否可利用？

| 检查项 | 高 | 中 | 低 |
|--------|----|----|-----|
| 配置依赖 | 默认配置 | 常见配置 | 特殊配置 |
| 环境依赖 | 无依赖 | 常见环境 | 特定环境 |
| 权限要求 | 无需权限 | 普通权限 | 特权 |

### 2. 稳定性

核心问题：利用是否可靠？

- 成功率
- 环境依赖
- 时序敏感
- 对抗性

### 3. 实战价值

核心问题：实际价值如何？

- 影响力
- 利用难度
- 隐蔽性

## 评估等级

### 稳定性等级

| 等级 | 标准 |
|------|------|
| 高 | 多次测试稳定成功，无环境依赖 |
| 中 | 成功率较高，或有轻微环境依赖 |
| 低 | 成功率不稳定，或强依赖特定环境 |

### 实战价值等级

| 等级 | 标准 |
|------|------|
| 高 | 高影响、高稳定、默认可利用、隐蔽 |
| 中 | 中等影响或有条件利用 |
| 低 | 低影响或需苛刻条件 |
