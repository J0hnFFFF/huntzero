## English

### Reporting Security Issues

If you discover a security vulnerability in this project, please report it responsibly:

1. **DO NOT** create public GitHub issues for security vulnerabilities
2. Contact us through appropriate channels
3. Allow time for security patches before public disclosure

### Responsible Disclosure

We follow responsible disclosure practices and will work with researchers to:
- Confirm and reproduce the issue
- Develop and release patches
- Credit contributors (if desired)

### Scope

This policy applies to:
- The Vuln Hunting Toolkit codebase
- Agent workflow definitions
- Related documentation

## 中文

### 报告安全问题

如果您发现本项目中的安全漏洞，请负责任地报告：

1. **请勿**为安全漏洞创建公开的 GitHub Issues
2. 通过适当渠道联系我们
3. 在公开披露前留出时间用于安全补丁开发

### 负责任的披露

我们遵循负责任的披露实践，并将与研究人员合作：
- 确认并重现问题
- 开发和发布补丁
- 给予贡献者荣誉（如需要）

### 适用范围

本政策适用于：
- 漏洞挖掘工具包代码库
- Agent 工作流定义
- 相关文档
