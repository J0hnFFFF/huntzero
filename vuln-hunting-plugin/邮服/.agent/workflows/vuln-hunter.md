# 邮服漏洞挖掘 (Mail Vuln Hunter)

专注于邮件服务器（SMTP/IMAP/POP3）的协议与逻辑深度挖掘。

## 分析角度

### 1. 协议状态机完整性
- 异常状态转换（未认证执行特权指令）
- 状态机乱序与绕过
- 异常断开重连处理

### 2. 解析逻辑健壮性
- 复杂格式解析（MIME/iCal/TNEF）
- 编码解码差异（Base64/QP/Uuencode）
- 边界条件处理（超长/空/特殊字符）

### 3. 数据流与存储
- 邮件投递路径分析
- 存储后端交互（File/DB/LDAP）
- 临时文件处理生命周期

### 4. 认证与授权边界
- 认证机制实现（SASL/NTLM）
- 权限降级与维持
- 跨用户/跨域数据隔离

## 挖掘方法论

### 协议压力测试
从状态机视角出发，构造非预期交互序列：
- 识别关键状态节点
- 尝试非法跳转路径
- 验证状态回滚逻辑

### 格式模糊测试 (Structural Fuzzing)
针对协议数据包结构进行测试：
- 保持协议骨架完整
- 指令参数变异
- 载荷内容的边界测试

### 逻辑缺陷分析
关注业务特性带来的风险：
- 中继策略绕过
- 投递规则逻辑漏洞
- 资源耗尽与竞争条件
