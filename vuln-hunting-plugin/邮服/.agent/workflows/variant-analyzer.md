# 邮服变体分析 (Mail Variant Analyzer)

基于已知漏洞模式，在协议处理与逻辑实现中挖掘同类变体。

## 挖掘维度

### 1. 指令同源性 (Command Homology)
分析共享相同处理逻辑的指令集：
- **平行指令**: 功能相似的指令 (e.g. `VRFY` vs `EXPN`)。
- **扩展指令**: 标准指令的 ESMTP 扩展版本。
- **逻辑复用**: 调用同一底层处理函数的不同入口。

### 2. 数据处理同构 (Data Handler Isomorphism)
关注数据处理管道的相似性：
- **解码器复用**: 相同解码逻辑在不同字段的应用。
- **解析器复用**: 相同格式解析器在不同上下文的调用。
- **存储路径**: 相似的文件操作逻辑。

### 3. 跨层级变体 (Cross-Layer Variants)
从当前层级向上下游延伸：
- **上游**: 代理层/网关层的相似问题。
- **下游**: 投递代理/存储后端的相似问题。

## 分析方法论

### 模式提取 (Pattern Extraction)
从已知问题中提取抽象模式：
- **控制流特征**: 关键函数调用序列。
- **数据流特征**: 污点传播路径。
- **逻辑特征**: 检查点缺失模式。

### 全局搜索 (Global Search)
利用代码分析工具进行全库扫描：
- **语义搜索**: 基于 AST/CPG 的结构化搜索。
- **文本搜索**: 关键模式的正则匹配。
- **补丁比对**: 分析历史补丁的覆盖范围，寻找漏网之鱼。
