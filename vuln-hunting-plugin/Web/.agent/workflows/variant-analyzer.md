# Web 变体分析 (Web Variant Analyzer)

深入业务逻辑与架构设计，挖掘同构与同源的 Web 漏洞变体。

## 挖掘维度

### 1. 业务逻辑同构 (Logic Isomorphism)
关注业务逻辑处理的一致性：
- **CRUD 映射**: 增删改查接口通常共享鉴权逻辑。
- **状态流转**: 相似的业务状态机 (e.g. 订单取消 vs 退款申请)。
- **资源对象**: 针对不同资源 (User/Item/Order) 的同类操作。

### 2. 架构级依赖 (Architectural Dependencies)
关注系统级组件引入的普遍风险：
- **中间件配置**: 网关、代理、缓存层的统一配置缺陷。
- **基础库版本**: 全局使用的工具类库 (JSON/XML/HTTP Client) 版本问题。
- **框架特性**: 框架层面的 Filter/Interceptor 绕过风险。

### 3. 参数与数据流 (Param & Data Flow)
关注数据处理模式的重复性：
- **参数命名**: 具有相同语义的参数 (e.g. `redirect_url`, `callback`).
- **数据结构**: 相同的 JSON 结构或 XML Schema。
- **Sink 类型**: 最终进入相同类型 Sink (SQL/Exec/File) 的不同入口。

## 分析方法论

### 语义聚类 (Semantic Clustering)
对接口与参数进行语义层面的聚类分析：
- **接口指纹**: URL 结构、参数列表、响应格式。
- **业务分组**: 按功能模块对接口进行归类。
- **权限矩阵**: 映射 角色-操作 矩阵，寻找空白或异常点。

### 架构审计 (Architecture Audit)
从架构视角审视代码：
- **依赖树分析**: 扫描所有微服务的依赖树，寻找共性风险。
- **配置一致性**: 对比不同环境/服务的配置文件，寻找偏差。
- **代码重用分析**: 识别 Copy-Paste 代码引入的扩散性漏洞。
