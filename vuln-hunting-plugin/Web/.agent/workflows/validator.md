# Web 评估验证 (Web Validator)

评估 Web 漏洞的真实业务危害、数据影响范围及防护对抗能力。

## 评估维度

### 1. 业务危害 (Business Impact)

核心问题：漏洞对业务CIA（机密性、完整性、可用性）的实际影响。

- **数据范围**: 影响单条数据、个人数据还是全站数据。
- **业务中断**: 是否会导致关键业务流程（如支付、登录）阻塞。
- **信誉影响**: 是否会导致用户被钓鱼、品牌受损。

### 2. 防护对抗 (WAF & Filter Evasion)

核心问题：Payload 是否具备在受控环境下的生存能力。

- **WAF 规则**: 评估常见 WAF 规则集的拦截情况。
- **语义混淆**: 验证是否存在语义等价但特征不同的 Payload。
- **编码传输**: 探索 HTTP 协议层面的绕过 (Chunked/Encoding)。

### 3. 无害化验证 (Non-destructive Verification)

核心问题：如何在不破坏生产环境的前提下证明漏洞存在。

- **时间盲注**: 使用延时而非数据提取。
- **逻辑探测**: 使用特定的报错或 DNSLog 而非执行危险命令。
- **只读操作**: 优先尝试读取非敏感数据验证越权。

## 验证方法论

### 最小化原则
构建最小可行 Payload (MVP)：
- 剥离冗余字符
- 精简攻击逻辑
- 降低被检测概率

### 响应差异分析
深度对比正常与异常响应：
- 状态码变化
- 响应时间波动
- 页面结构差异 (DOM Tree Diff)
