# 浏览器变体分析 (Browser Variant Analyzer)

深入代码模式与优化逻辑，挖掘同类浏览器漏洞变体。

## 挖掘维度

### 1. 生命周期管理范式 (Lifecycle Paradigms)
关注对象生命周期的管理范式：
*   **手动引用计数**: 检查相似的 `RefPtr/WeakPtr` 使用逻辑。
- **所有权转移**: 检查 `std::move` 或 `Pass`类语义的使用。
- **对象销毁回调**: 检查析构函数或清理逻辑中的副作用。

### 2. 优化阶段同源性 (Optimization Phase Homology)
关注编译器优化阶段的通用逻辑：
- **同类节点处理**: 相似 IR 节点的优化规则 (e.g. `CheckBounds` elimination)。
- **分析逻辑复用**: 范围分析、类型分析在不同上下文的应用。
- **去优化检查**: 检查点插入逻辑的完整性。

### 3. 接口规范与实现 (Interface & Implementation)
关注接口定义与实现的匹配度：
- **IDL 覆盖**: 扫描所有 Web IDL 定义的接口，寻找相似的参数类型或回调逻辑。
- **IPC 定义**: 扫描所有 Mojo/IPDL 定义，寻找相似的序列化/反序列化逻辑。

## 分析方法论

### 结构化代码搜索 (Structural Code Search)
超越文本搜索，理解代码结构：
- **AST 匹配**: 匹配特定的语法树结构。
- **数据流查询**: 追踪特定类型数据的流向。
- **控制流分析**: 寻找特定的执行路径模式。

### 补丁间隙分析 (Patch Gapping)
分析补丁的完整性：
- **同类代码未修**: 检查补丁是否遗漏了相似的代码块。
- **补丁逻辑绕过**: 分析补丁引入的检查是否可以被绕过。
- **变体回归**: 检查新引入的代码是否重犯了历史错误。
