# 浏览器漏洞挖掘 (Browser Vuln Hunter)

专注于浏览器渲染引擎与 JavaScript 引擎的深层机制挖掘。

## 分析角度

### 1. 对象生命周期 (Object Lifecycle)
- 对象的创建、引用、销毁过程
- 垃圾回收 (GC) 对对象的影响
- 跨上下文/跨线程的对象传递

### 2. 编译优化管道 (Optimization Pipeline)
- JIT 编译器的类型推断 (Typer)
- 范围分析与边界检查消除
- 逃逸分析与对象分配消除
- 优化与去优化 (Deoptimization) 的状态同步

### 3. 跨进程交互 (IPC & Sandbox)
- 渲染进程与浏览器进程的通信边界
- 消息序列化与反序列化
- 句柄与共享内存的生命周期管理

### 4. DOM 与 绑定层 (Bindings)
- 接口定义 (IDL) 与 C++ 实现的映射
- 事件传播与回调执行顺序
- 节点树变动与渲染更新逻辑

## 挖掘方法论

### 语义感知的模糊测试
并非随机变异，而是基于语言语法的生成：
- 构造语义正确的复杂代码结构
- 针对特定优化阶段触发优化规则
- 甚至利用语法错误触发异常路径

### 资源竞争与时序分析
关注并发模型下的状态一致性：
- 强制改变执行顺序 (Yield/Sleep)
- 构造复杂的事件处理链
- 干扰主线程与 Worker 线程的同步

### 源码与补丁审计
- 关注新特性的代码提交
- 分析历史漏洞的修复补丁 (寻找 Regression 或 Incomplete Fix)
- 对比设计文档与实现代码
