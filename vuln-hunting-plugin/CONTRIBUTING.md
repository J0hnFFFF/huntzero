## English

### Welcome

We appreciate your interest in contributing to Vuln Hunting Toolkit! This project is for **authorized security research and educational purposes** only.

### How to Contribute

1. **Fork the repository**
2. **Create a feature branch**: `git checkout -b feature/module-name`
3. **Make your changes** with clear commit messages
4. **Submit a Pull Request**

### Contribution Areas

- New vulnerability hunting modules
- Improved agent workflows
- Documentation improvements (especially bilingual)
- Bug fixes and optimizations

### Coding Standards

- Follow existing code structure
- Include bilingual documentation
- Maintain security best practices
- Test thoroughly before submitting

### Security Disclosure

If you discover a security issue, please report it responsibly. Do NOT create public issues for security vulnerabilities.

## 中文

### 欢迎

感谢您对漏洞挖掘工具包的贡献兴趣！本项目仅用于**授权的安全研究和教育目的**。

### 如何贡献

1. **Fork 本仓库**
2. **创建功能分支**: `git checkout -b feature/module-name`
3. **提交您的更改**，并附上清晰的提交信息
4. **提交 Pull Request**

### 贡献领域

- 新增漏洞挖掘模块
- 改进 Agent 工作流
- 文档改进（尤其是中英双语）
- Bug 修复和优化

### 代码规范

- 遵循现有代码结构
- 包含中英双语文档
- 保持安全最佳实践
- 提交前充分测试

### 安全披露

如果您发现安全问题，请负责任地报告。请勿为安全漏洞创建公开 Issue。
