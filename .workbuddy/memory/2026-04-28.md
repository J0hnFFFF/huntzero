### ✅ 补充1：`semantic_helper.py` 支持 JS/TS/Go/Java 污点追踪

**问题**：`_get_callers_with_context()` 的 `caller_queries` 只支持 Python 和 JavaScript，Go/Java/TypeScript 完全不支持。

**修改**：
- 重写 `_get_callers_with_context()`，改用通用策略：先找所有 call site（`_find_call_sites`），再向上找最近函数定义（`_find_enclosing_function`）
- 新增 `_find_call_sites(tree, src, lang, fn_name)` — 兼容全部 8 种语言
- 新增 `_find_enclosing_function(tree, src, lang, call_line)` — 同上
- 同步更新 `cmd_call_graph` 的 `call_site_queries` 和 `def_queries`（之前也只支持 Python/JS）
- 同步更新 `cmd_scope_extract` 的 `q_str`（之前也只支持 Python/JS）
- 文件：`tools/semantic_helper.py`（原 489 行 → 现在约 750 行）

**支持语言**：`python | javascript | typescript | go | java | rust | c | cpp`（共 8 种）

### ✅ 补充2：`BayesianConfidenceEngine` 改为从数据学习因果强度

**问题**：`DEFAULT_STRENGTH = 0.85` 是拍脑袋的固定值，不反映真实因果强度。

**修改**：
- 替换整个 `BayesianConfidenceEngine` 类为可学习版本
- 新增 `__init__(strength_path)` 参数，支持从磁盘加载已学习的 strength matrix
- 新增 `record_outcome(h_id, confirmed)` — 当 PoC 验证结果回来时调用
- 新增 `_update_strength_for_pair(parent_id, child_id, confirmed)` — 用 Laplace smoothing 估计 P(child|parent)
- 新增 `learn_from_outcomes(outcomes)` — 批量从历史数据学习
- 新增 `save()` / `_load_from_file()` — 持久化到 `.bayesian_strength.json`
- 新增 `get_strength_stats()` — 返回学习状态统计
- `MIN_SAMPLES_TO_USE_LEARNED = 3`：至少 3 个样本才使用学习值，否则 fallback 到默认值
- 持久化路径：`{work_dir}/.bayesian_strength.json`
- 文件：`engine/blackboard.py`（该类从约 60 行 → 约 160 行）

**学习公式**（Laplace smoothed）：
```
P(child|parent) = (hits + alpha) / (total + 2*alpha)
strength = min(1.0, max(0.0, conditional / base_rate))
```

### ✅ 补充3：`ExploitPrerequisites` 增加自动解析（静态分析 + LLM 推断）

**问题**：`ExploitPrerequisites` 只是空数据结构，没有自动填充逻辑。

**修改**：

  - 先静态分析，再 LLM 推断（仅当 LLM 置信度 ≥ 0.6 时覆盖）
  - 合并 `target_env` 信息判断 `is_satisfiable`
- 实现 `batch_analyze(findings, code_map, use_llm)` — 批量分析
- CLI 入口：`python tools/exploit_analyzer.py --desc "..." [--code file] [--no-llm]`
